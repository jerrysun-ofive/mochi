# Security Policy

Mochi is pre-release software. Do not test vulnerabilities against folders or data you do not own.

Please report suspected vulnerabilities privately through GitHub's security-advisory feature. Include the affected version, reproduction steps, expected impact, and whether file contents or credentials may have been exposed. Do not include real sensitive files, API keys, or security-scoped bookmark data.

Filesystem safety and provider-boundary regressions are treated as release blockers.
